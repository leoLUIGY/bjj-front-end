# 🥋 BJJ Catalog Front-End

Aplicação web para gerenciamento de equipes de Jiu-Jitsu, desenvolvida com HTML, CSS e JavaScript, consumindo a API BJJ Catalog.

## 🚀 Funcionalidades

* Listar equipes cadastradas
* Buscar equipes por nome
* Visualizar detalhes de uma equipe
* Cadastrar novos times
* Editar informações existentes
* Remover equipes

## 🛠 Tecnologias

* HTML5
* CSS3
* JavaScript
* Fetch API

## 📁 Estrutura

```text
bjj-front-end/
├── index.html
├── Style.css
└── Script.js
```

## ▶️ Como executar

1. Clone o repositório:

```bash
git clone https://github.com/seu-usuario/bjj-front-end.git
```

2. Abra o arquivo `index.html` no navegador ou utilize a extensão Live Server do VS Code.
